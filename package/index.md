# Job search

Root index. Read this first, then open what you need.

## Start here

- [[resume-master]] — the user's master data. Source of truth for every resume.
- [[AGENTS]] — the vault contract.
- [[BLUEPRINT]] — the build manual: skill specs and script pseudocode. Permanent rebuild reference.

## Pipeline

- `raw/jobs/` — listings as markdown, passed screening (working set)
- `raw/jobs/done/` — archived: stale, rejected, expired
- `workflow/shortlisted/` — worth applying
- `workflow/processing/` — applied or interviewing
- `workflow/interviews/` — per-company prep

## Records

- [[log]] — append-only audit trail.
- [[tasks]] — shared queue.
